# Toma de inventario · versión servidor (F4.0)

App web instalable (PWA) para el conteo físico de inventario. Habla con el servidor en Supabase (función `api`).
No contiene claves ni datos: la dirección del servidor (`config.js`) no es secreta; la protegen el inicio de sesión y las reglas del servidor.

Archivos: index.html, app.js, styles.css, sw.js, config.js, manifest.webmanifest e iconos.
Para publicarla: sube estos archivos a la raíz del repositorio y activa GitHub Pages (Settings > Pages > main > / (root)).
